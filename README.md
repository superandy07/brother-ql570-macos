# Brother QL-570 on modern macOS

Two things for the **Brother QL-570** label printer:

1. **[Turn off its 4-hour auto power-off](#turn-off-auto-power-off)** from a
   Mac with one USB command. Brother's tool for this is Windows-only and
   officially limited to some units.
2. **[A native macOS driver](#native-driver)** for Apple Silicon and Intel.
   Brother's last macOS driver (2018) is Intel-only, so it needs Rosetta,
   which Apple is phasing out.

> **Tested on:** one QL-570 (UK unit) over USB, macOS 15 (Apple Silicon).
> Reports from other units are welcome.

---

## Turn off auto power-off

The QL-570 switches itself off after **4 hours** without a job. That's
a problem if it's shared from an always-on Mac, because nothing can turn it
back on remotely.

Brother's *Auto power-off setting tool* (`autopoff.exe`) can change this, but
it only runs on Windows. Analysing it showed that the setting is a single
command, `ESC i U A`. The value is in **10-minute units**, and `00` means
never:

| Setting | Value |
|---|---|
| None | `00` |
| 1 hour | `06` |
| 2 hours | `0C` |
| 4 hours (factory) | `18` |
| 8 hours | `30` |
| 12 hours | `48` |

`qlstatus` sends it over USB. It needs no driver and no admin rights.

```bash
make build/qlstatus
build/qlstatus                              # normal status: model, media, errors
build/qlstatus -x "1b 69 55 41 01"          # read the setting (reply byte 30)
build/qlstatus -x "1b 69 55 41 00 00"       # set auto power-off to None
build/qlstatus -x "1b 69 55 41 00 18"       # back to the 4-hour default
```

**Check it worked.** Read the setting again: byte 30 of the 32-byte reply
should now be `00`. On the author's printer the setting survived repeated
power cycles.

**Caveats:**
- Brother's tool first checks that the printer supports the feature, by
  reading a few memory locations and expecting `0xAA`. `qlstatus` skips those
  checks. If your printer doesn't support the setting, the read reply simply
  won't show the change.
- The command is undocumented, so use it at your own risk.

### Keep-alive (optional backup)

`keepalive/` installs a LaunchDaemon that sends a harmless status request
every hour. The request resets the printer's idle timer without printing
anything.

```bash
sudo keepalive/install_keepalive.sh            # install
sudo keepalive/install_keepalive.sh --remove   # remove
```

It logs one line per check to `/Library/Logs/ql570-keepalive.log`.

## Native driver

`src/rastertoql570.c` is a CUPS filter that turns macOS's 8-bit greyscale
raster into Brother's published QL raster commands (*QL-500…1060N command
reference*, v6.0).

| File | What it is |
|---|---|
| `ppd/Brother_QL-570.ppd` | Generated by `tools/genppd.py`, with Brother's 52 label sizes and the same option names, so existing documents and presets keep working. |
| `tools/capture_brother.sh` | Runs Brother's filter on test labels, so the comparison test has something to compare against. |
| `tools/qldecode.py` | Decodes QL raster output. |
| `tools/edsim.c` | Halftone simulator used to study Brother's error diffusion. |

### Matching Brother's driver

With Brother's driver installed, `tools/capture_brother.sh` then `make test`
compare 81 jobs:
- every label size (including Brother's wide "×2/×3/×4" pages, which print as
  separate strips)
- every option value: quality, resolution, halftone, brightness, contrast,
  cutting and mirror
- multi-page jobs

On the author's printer, all 81 cases had identical commands and row counts.

- **"For logo and text" (binary) and "For text and graphics" (4×4 dither)**
  match Brother's output dot for dot.
- **"For general labels" (error diffusion, the default)** uses Brother's
  *measured* tone curve with Floyd–Steinberg. The dots form a different
  pattern, but the tone is the same: mean darkness differs by about 0.2%.
- **Deliberate differences:**
  - "Trim tape after data" really trims blank tape; Brother's filter didn't.
  - Copies are produced by macOS (`cupsManualCopies`), because Brother's
    filter ignored them.

No Brother code or files are included. The label sizes are dimensions taken
from Brother's PPD, and the tone curve is a measurement of its output.

### Install

```bash
make
sudo ./install.sh
```

This adds the queue **`Brother_QL_570_Native`** next to any existing queue.
`sudo ./switch_to_native.sh` then shares it, removes the `Brother_QL_570`
queue, and removes Brother's driver unless another queue still uses it. Back
up `/Library/Printers/Brother` first if you might want it back.

To uninstall: `sudo ./uninstall.sh`.

## Requirements

- macOS 12 or later. The build is universal (arm64 + x86_64).
- Xcode Command Line Tools: `xcode-select --install`.
